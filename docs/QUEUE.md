# 승인 목록 사용 설명서

캐러셀을 올리기 전에 내용을 확인하고, 무엇이 언제 올라갔는지 기록하는 화면입니다. 이 컴퓨터 안에서만 열립니다.

## 여는 방법

실행 파일을 두 번 누르면 브라우저에 승인 목록이 열립니다. 검은 창은 쓰는 동안 닫지 마세요. 닫으면 화면이 멈춥니다.

처음 설정할 때는 아래처럼 게시물 폴더를 지정합니다.

```bash
node queue.mjs --dir <게시물 폴더들이 있는 상위 폴더> --open
```

`make.mjs`로 만든 결과 폴더(`01.png`와 `caption.txt`가 있는 폴더)는 자동으로 목록에 나타납니다.

## 쓰는 순서

| 순서 | 화면에서 할 일 |
|:--|:--|
| 1 | **승인대기** 탭에서 이미지와 캡션을 확인합니다. 이미지를 누르면 크게 보입니다. |
| 2 | 괜찮으면 **승인**, 고칠 곳이 있으면 **수정 요청**을 누르고 내용을 적습니다. |
| 3 | **승인** 탭에서 **캡션 복사**와 **이미지 폴더 열기**로 인스타에 직접 올립니다. |
| 4 | 올린 뒤 **인스타에 올렸어요**를 누릅니다. 게시물 주소는 넣어도 되고 비워도 됩니다. |
| 5 | **발행완료** 탭에 날짜와 함께 기록됩니다. |

## 알아 둘 규칙

- 승인하지 않은 게시물은 발행 완료로 기록할 수 없습니다.
- 승인한 뒤 이미지나 캡션이 바뀌면 승인이 풀리고 **승인대기**로 돌아옵니다.
- 수정 요청한 게시물을 다시 만들어도 **승인대기**로 돌아옵니다.
- 발행 완료 기록은 되돌릴 수 없습니다.
- 상태는 각 게시물 폴더의 `status.json`에 저장됩니다. 직접 고치지 마세요.

## 아직 없는 기능

- 인스타 자동 업로드 (공식 연동과 계정 권한이 필요합니다)
- 승인 대기 알림 (슬랙 연결 후 추가)
- 유튜브·카카오톡 발행
